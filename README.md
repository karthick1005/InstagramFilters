# 🎨 Instagram Filter Application

A sleek and easy-to-use web application that lets you upload images, apply Instagram-like filters (including custom adjustments), and download the filtered image — all in the browser!

🌐 **Live Demo**: [instagramfilters.vercel.app](https://instagramfilters.vercel.app/)

---

## ✨ Features

- 📤 Upload your own image
- 🎨 Choose from pre-built Instagram-style filters
- 🎛️ Use custom sliders to fine-tune filter properties like brightness, contrast, blur, hue, and more
- 📥 Download the filtered image directly
- ⚡ Lightning-fast, built with React.js
- 📱 Fully responsive design for mobile and desktop

---

## 🛠 Tech Stack

- **React.js** – Frontend framework
- **CSS Filters** – For image effects
- **HTML5 File API** – Image upload and processing
- **Vercel** – Deployment
